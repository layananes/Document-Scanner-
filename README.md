# Document Scanner

### What this repo consists of
- Python code file
- Image used to test the scanner

### What the project is about
This project is about document scanning. It uses input images of papers, and transforms them into a scanned image. 
Warping and recoloring is also used to give it a true scanned look. 

Testing it on other images was challening, and I am guessing it is due to the different sizes of the images, since all the effects are applied and resized to fit the image first uploaded.
